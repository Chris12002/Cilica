# Lazy-prefix Mac ARM64 experiment — 2026-10-09

This is a separate, non-production comparison of the frozen approved DiffPlex
workload. It does not change Cilica runtime or compiler source and does not
approve production adoption.

## Scope and validity

The transform is limited to one synchronous `valid_roots` call. It records and
queries only the ownership-list prefix visited by that call. No result survives
the call, frame push/pop, allocation, collection, observer callback, reentrant
validation, or runtime instance. The linked inventory, tracing, marking,
allocation publication, malformed-frame checks, and cross-instance checks remain
authoritative.

The generated input is the frozen native source
`51d73790b77e9bd83d330785bcc12f975153840a9e8d37aec9462719083d26d7` from the
approved workload manifest (`Cilica` source pin `3d0bb53e94b5356cbbe59fae3c2ebca93af68fc8`,
DiffPlex pin `f500e73f28e28813f942f1f16dec5a34b40e48e3`). The experiment is
therefore a workload-pinned measurement, not a claim about every current
feature-head generated closure.

## Correctness and accounting

- Transformer unit checks: 3/3 passed.
- Authored reducer: 204,682 assertions passed at both O0 and O2 with
  AddressSanitizer/UndefinedBehaviorSanitizer.
- Forced-GC transcript: baseline and transformed O0/O2 outputs match, checksum
  `6146`; all 523 observations are present.
- Negative unreadable-tail cases rejected under sanitizers at O0/O2.
- Clean diagnostic frame maxima: baseline 368 bytes, transformed 432 bytes;
  sanitizer authored cases stayed below the 2 KiB gate (O0 1,968 bytes; O2
  352/256 bytes).
- Authored resource checks retained the existing managed limits and bounded
  experimental scratch to 8,192 slots/65,536 bytes. The largest observed
  scratch peak was 65,536 bytes; the test-enabled instance was 208 bytes.

Independent read-only review by the compatibility lane found no concrete
ownership, corruption, or frame blocker for this bounded experiment. The review
does not approve production adoption and retains the limitations around 32-bit
execution, arbitrary native corruption, and callbacks/configuration mutation
during a query.

## Fresh Mac ARM64 timing

Three fresh processes per variant, alternating order; O2, NDEBUG, no exceptions,
no RTTI, identical workload, 300 ms warmup, seven samples, 16 operations/sample.
Checksums were verified outside the timed interval.

| Variant | Median | Range | Cold first call | No-op process |
|---|---:|---:|---:|---:|
| Baseline | 178.145 ms/op | 143.640–201.353 ms/op | 32.032 ms | 3.39–5.75 ms |
| Lazy prefix | 28.406 ms/op | 25.167–32.143 ms/op | 11.235 ms | 3.39–3.85 ms |

The median speedup is **6.115x**. Paired process-median ratios are
**5.872x, 6.546x, and 6.021x**. Host load snapshots bracketed every process:
load average ranged from 4.91 to 6.56 on a 14-CPU host. These values are
informational; no ratio is a correctness or adoption gate.

The retained raw Mac evidence is in
`artifacts/performance-lazy-prefix-mac-20261008/evidence/evidence`, with
source/executable hashes, transcript outputs, `clean-results.json`, and
`host-load.jsonl`. The earlier Linux/Docker 6.867x result remains separate and
must not be treated as the Mac result.

Two harness-only host restrictions were retained as limitations: direct `sysctl`
load reads were denied, so portable `getloadavg()` snapshots were used; the
first compiler attempt could not use the host temporary path and was rerun with
task-owned `/tmp` scratch. Neither affected source correctness.

## Residual profile and next experiment

The matched O2 diagnostic profile retains the same 21 samples and 16-operation
batch for both variants. Root validation still performs 824 calls and 122,000
root-slot checks per diff; the transform changes only the ownership lookup work.

| Diagnostic scope | Baseline | Lazy prefix |
|---|---:|---:|
| Median diagnostic time | 189.016 ms/op | 28.850 ms/op |
| Root-validation inclusive share | 88.31% | 27.28% |
| Collection share | 0.18% | 1.09% |
| Allocation-inclusive share | 88.55% | 28.58% |

The remaining evidence points to generated step execution, receiver/type checks,
and dispatch rather than another ownership-index variant. The next bounded
candidate is an exact receiver/descriptor dispatch cache scoped to one
synchronous call. It must reject replacement, null-order changes, generic or
variance changes, cross-instance reuse, and reentrant/collection boundaries;
otherwise it will be rejected. No production memory budget is being changed.

Residual raw profiles and matching hashes are retained under
`artifacts/performance-lazy-prefix-mac-20261008/residual-20261009`.
