# ADR 0122: Managed decimal formatting trial

Status: Accepted

## Decision

Begin the managed library port with invariant decimal text for the four 32/64-bit
integer types. Adapt the pinned dotnet/runtime two-digit division loop and
unsigned negative-magnitude handling. Retain the original source, MIT license,
notices and source hashes in the repository. Mark adaptations explicitly in
`library/provenance.json`.

Compile only the small adapted helper in `Cilica.Library`, using checked managed
string composition in place of pointers and runtime-private allocation. This
tests the existing IL-to-C++ pipeline without granting unsafe privileges. Native
output remains independently generated by Cilica and its runtime.

The helper guarantees decimal text only. System numeric member mapping, format
providers, precision, spans, UTF-8 and cached string identity need separate
decisions and evidence. The untouched upstream file is reference material, not
an assertion that all its members compile. Build provenance production and mapped
implementation-closure auditing remain required gates.

## Evidence and review

All three focused tests pass: 8,192 managed randomized/boundary text comparisons
and 8,976 repeated native result checks at O0/O2 with ASan/UBSan. Native checks
compare lengths and every code unit, collect before each allocation, and exercise
exact/short frame budgets and cleanup. Review checked signed minimum magnitude,
unsigned division, digit ordering and reference liveness across concatenations.
No remaining actionable issue was found. The full solution builds without warnings.
